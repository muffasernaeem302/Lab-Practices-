# 🧪 Lab Practices

> **A structured collection of laboratory exercises, practical implementations, experiments, and hands-on programming work developed throughout the learning journey.**

---

## 📌 Overview

**Lab Practices** is an academic programming repository created to organize and document hands-on laboratory work.

The repository focuses on learning through implementation — taking concepts discussed in lectures and applying them through practical exercises, experiments, problem-solving tasks, and small programs.

Rather than focusing on a single software project, this repository represents a collection of practical work developed across different laboratory sessions.

---

# 🎯 Objectives

The main objective of this repository is to strengthen programming and problem-solving skills through consistent practical implementation.

### Key Goals

* 🧠 Apply theoretical concepts through code
* 💻 Develop practical programming skills
* 🧩 Improve logical problem-solving
* 🔍 Experiment with different programming concepts
* 🛠️ Understand how software behaves through implementation
* 📝 Maintain organized laboratory work
* 📈 Track development and learning progress
* 🔄 Improve solutions through debugging and iteration

---

# 🧪 Laboratory Approach

Each practical exercise follows a simple learning cycle:

```text
        📖 Learn
           │
           ▼
       🧠 Understand
           │
           ▼
        💻 Implement
           │
           ▼
        🧪 Test
           │
           ▼
       🐛 Debug
           │
           ▼
       🔧 Improve
           │
           ▼
        📈 Learn More
```

The purpose of laboratory practice is not only to complete an exercise, but to understand the underlying concept and develop the ability to implement it independently.

# 🐛 Debugging Workflow

Debugging is treated as an important part of laboratory practice.

A structured debugging process:

```text
Identify Error
      ↓
Understand Cause
      ↓
Reproduce Problem
      ↓
Apply Fix
      ↓
Test Again
      ↓
Verify Result
```

This approach helps develop debugging skills that are essential in real-world software development.
